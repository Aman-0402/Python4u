🚀 Measure Before You Optimize

Don't guess what's slow — measure it. Python gives you simple tools to time code and inspect memory, so you fix the actual bottleneck instead of the wrong line.

⏱️ 1. Timing Code

import time

start = time.time()

total = 0
for i in range(1_000_000):
    total += i

end = time.time()
print(f"Loop took {end - start:.4f} seconds")
Loop took 0.0821 seconds

Comparing two approaches

import time

start = time.time()
squares = [n * n for n in range(1_000_000)]
print(f"List comprehension: {time.time() - start:.4f}s")

start = time.time()
squares = []
for n in range(1_000_000):
    squares.append(n * n)
print(f"For loop: {time.time() - start:.4f}s")
List comprehension: 0.0512s For loop: 0.0894s

💾 2. Memory — Checking Object Size

import sys

small_list = [1, 2, 3]
big_list = list(range(1000))

print(sys.getsizeof(small_list))   # bytes used by the list itself
print(sys.getsizeof(big_list))
88 8856

🌀 3. Generators Save Memory

import sys

list_version = [n * n for n in range(100000)]
gen_version  = (n * n for n in range(100000))

print(sys.getsizeof(list_version))   # holds ALL 100,000 results
print(sys.getsizeof(gen_version))    # holds almost nothing — lazy
824456 200

The list stores every value now. The generator stores almost nothing — it produces values one at a time, only when asked. See Iterators & Generators for more.

📦 4. __slots__ — Slimmer Objects

By default, every object stores its attributes in a flexible dictionary. For classes creating thousands of small objects, __slots__ removes that overhead.

import sys

class StudentNormal:
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

class StudentSlim:
    __slots__ = ("name", "marks")
    def __init__(self, name, marks):
        self.name = name
        self.marks = marks

a = StudentNormal("Ravi", 78)
b = StudentSlim("Ravi", 78)

print(sys.getsizeof(a.__dict__))   # normal object keeps a dict
print(sys.getsizeof(b))            # slotted object skips the dict
104 56
💡 Only worth using __slots__ when creating many thousands of instances of a small class — the memory savings add up. Adds a rule: no new attributes beyond the ones listed.

🧭 5. Quick Wins Checklist

SituationDo this
Building a list just to loop over it onceUse a generator instead
Repeatedly concatenating strings in a loopUse "".join(list_of_strings)
Looking up items by value oftenUse a set or dict, not a list (O(1) vs O(n))
Not sure what's slowTime it first — don't guess

String joining example

# Slow — creates a new string every iteration
result = ""
for word in ["Python", "is", "fun"]:
    result += word + " "

# Fast — builds once
result = " ".join(["Python", "is", "fun"])
print(result)
Python is fun

🧑‍💻 Practice

🚀 Challenge: Time how long it takes to check if 999999 is in a list of 1,000,000 numbers vs a set of the same numbers. 
import time

numbers_list = list(range(1000000))
numbers_set = set(numbers_list)

start = time.time()
999999 in numbers_list
print(f"List lookup: {time.time() - start:.6f}s")

start = time.time()
999999 in numbers_set
print(f"Set lookup: {time.time() - start:.6f}s")
# Set lookup is dramatically faster — O(1) vs O(n)

✍️ Chapter Summary

  • time.time() — measure how long code takes
  • sys.getsizeof() — check an object's memory footprint
  • Generators use far less memory than building a full list
  • __slots__ shrinks memory for classes with many instances
  • Use set/dict for fast lookups instead of scanning a list
