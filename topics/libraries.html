import numpy as np

📦 1. Creating Arrays

1D Array

arr = np.array([1, 2, 3, 4])
print(arr)  # Output: [1 2 3 4]

2D Array (Matrix)

matrix = np.array([[1, 2], [3, 4]])
print(matrix)
[[1 2] [3 4]]

⚙️ 2. Useful Array Operations

arr = np.array([1, 2, 3, 4])
print(arr + 5)          # [6 7 8 9]
print(arr * 2)          # [2 4 6 8]
print(np.mean(arr))     # Average = 2.5
print(np.sqrt(arr))     # Square roots
🧠 NumPy applies operations element-wise (vectorized). You don't need loops!

🧪 3. More Array Functions

print(np.max(arr))      # 4
print(np.min(arr))      # 1
print(np.sum(arr))      # 10
print(np.std(arr))      # Standard deviation

📏 4. Array Shapes and Dimensions

print(arr.shape)        # (4,) → 1D with 4 elements
print(matrix.shape)     # (2, 2) → 2x2 matrix
print(arr.ndim)         # 1 (1D array)
print(matrix.ndim)      # 2 (2D array)

🔄 5. Creating Special Arrays

np.zeros((2, 3))     # 2x3 array of zeros
np.ones((3, 2))      # 3x2 array of ones
np.arange(0, 10, 2)  # [0 2 4 6 8]
np.linspace(1, 5, 4) # 4 numbers from 1 to 5

🔄 6. Reshaping Arrays

arr = np.array([1, 2, 3, 4, 5, 6])
reshaped = arr.reshape((2, 3))
print(reshaped)
[[1 2 3] [4 5 6]]

🔍 7. Indexing & Slicing

arr = np.array([10, 20, 30, 40])
print(arr[1])       # 20
print(arr[1:3])     # [20 30]
matrix = np.array([[5, 6], [7, 8]])
print(matrix[1][0])  # 7

📥 1. Importing pandas & Creating DataFrames

import pandas as pd

data = {
    "Name": ["Aman", "Elon", "John"],

}

🔍 5. Filtering Rows

Put a condition inside [ ] to keep only the rows that match — this is how you answer "which students scored above 85?"

data = {"Name": ["Aman", "Elon", "John", "Priya"], "Marks": [90, 85, 60, 95]}
df = pd.DataFrame(data)

toppers = df[df["Marks"] > 85]
print(toppers)
Name Marks 0 Aman 90 3 Priya 95

Combine conditions with & (and) / | (or) — wrap each condition in its own parentheses.

result = df[(df["Marks"] > 60) & (df["Marks"] < 95)]
print(result)
Name Marks 0 Aman 90 1 Elon 85

➕ 6. Adding & Dropping Columns

df["Grade"] = ["A", "A", "C", "A"]        # add a new column
print(df)
Name Marks Grade 0 Aman 90 A 1 Elon 85 A 2 John 60 C 3 Priya 95 A
df["Bonus"] = df["Marks"] + 5             # new column built from another
df = df.drop("Bonus", axis=1)             # drop a column (axis=1 = column)
print(df.columns)
Index(['Name', 'Marks', 'Grade'], dtype='object')

📊 7. groupby — Summarize by Category

groupby() answers questions like "average marks per grade." It splits the data into groups, applies a calculation to each, then combines the results.

data = {
    "Name": ["Aman", "Elon", "John", "Priya"],
    "Grade": ["A", "A", "C", "B"],
    "Marks": [90, 85, 60, 78]
}
df = pd.DataFrame(data)

avg_by_grade = df.groupby("Grade")["Marks"].mean()
print(avg_by_grade)
Grade A 87.5 B 78.0 C 60.0 Name: Marks, dtype: float64

❓ 8. Handling Missing Data

Real data often has gaps. pandas represents a missing value as NaN.

import numpy as np

data = {"Name": ["Aman", "Elon", "John"], "Marks": [90, np.nan, 60]}
df = pd.DataFrame(data)

print(df.isnull())          # True where data is missing
Name Marks 0 False False 1 False True 2 False False
df_clean = df.dropna()              # remove rows with any missing value
print(df_clean)

df_filled = df.fillna(0)            # replace missing values with 0
print(df_filled)
Name Marks 0 Aman 90.0 2 John 60.0 Name Marks 0 Aman 90.0 1 Elon 0.0 2 John 60.0
💡 dropna() throws away incomplete rows — use when missing data is rare. fillna() keeps every row but guesses a value — use when you have a sensible default (0, average, "Unknown").

🔗 9. Merging Two DataFrames

Combine two tables that share a common column — like a SQL join.

students = pd.DataFrame({"ID": [1, 2, 3], "Name": ["Aman", "Elon", "John"]})
marks = pd.DataFrame({"ID": [1, 2, 3], "Marks": [90, 85, 60]})

combined = pd.merge(students, marks, on="ID")
print(combined)
ID Name Marks 0 1 Aman 90 1 2 Elon 85 2 3 John 60

on="ID" tells pandas which column links the two tables — rows are matched by that shared value.
