🕸️ Chapter 42

Graphs — BFS & DFS

Nodes connected by edges — for anything that isn't a straight line or a strict hierarchy. Friend networks, maps, dependencies.

🕸️

🕸️ Connections, Not Order

A tree has one parent per node and no cycles. A graph is more general — any node can connect to any other node, in any pattern, including loops.

⚡ 1. What is a Graph?

TermMeaning
Node (vertex)A single point — a person, a city, a webpage
EdgeA connection between two nodes
Directed graphEdges have a direction (A → B doesn't mean B → A) — e.g. "follows" on social media
Undirected graphEdges go both ways — e.g. "friends with" is mutual

🗺️ Real-Life Analogy

A road map: cities are nodes, roads are edges. Google Maps finding a route is literally a graph search problem.

🧱 2. Representing a Graph — Adjacency List

The simplest way: a dictionary mapping each node to a list of its neighbors.

graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C", "E"],
    "E": ["D"]
}
# A connects to B and C
# B connects to A and D
# ...and so on

Visually: A—B, A—C, B—D, C—D, D—E. This is exactly how dict hashing makes graph lookups fast — graph["D"] instantly gives you D's neighbors.

🌊 3. Breadth-First Search (BFS) — Explore Level by Level

Visit all neighbors first, then their neighbors, then theirs — spreading outward in rings. Uses a queue.

from collections import deque

def bfs(graph, start):
    visited = set()
    queue = deque([start])
    visited.add(start)
    order = []

    while queue:
        node = queue.popleft()      # FIFO — process oldest-added first
        order.append(node)

        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

    return order

graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C", "E"],
    "E": ["D"]
}

print(bfs(graph, "A"))
['A', 'B', 'C', 'D', 'E']

BFS explores A's neighbors (B, C) completely before moving on to D — that's the "level by level" pattern. BFS is what finds the shortest path in an unweighted graph.

🕳️ 4. Depth-First Search (DFS) — Go Deep First

Follow one path as far as possible before backtracking. Uses a stack — or, just as naturally, recursion.

def dfs(graph, start, visited=None, order=None):
    if visited is None:
        visited = set()
        order = []

    visited.add(start)
    order.append(start)

    for neighbor in graph[start]:
        if neighbor not in visited:
            dfs(graph, neighbor, visited, order)   # go deep before backtracking

    return order

graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C", "E"],
    "E": ["D"]
}

print(dfs(graph, "A"))
['A', 'B', 'D', 'C', 'E']

DFS dives from A → B → D → E before backtracking to check C — the opposite exploration pattern from BFS, even on the same graph.

⚖️ 5. BFS vs DFS

BFSDFS
ExploresLevel by level (breadth)One path fully, then backtracks (depth)
Data structureQueueStack (or recursion)
Finds shortest path?Yes (unweighted graphs)No guarantee
Good forShortest path, "closest" connections, level-order tasksExploring all paths, cycle detection, maze solving
💡 The visited set in both algorithms isn't optional — without it, a graph with cycles (A connects to B, B connects back to A) would loop forever. It's the same O(1) hashing trick from the Hashing chapter, used to remember where you've already been.

🚀 Challenge: Write is_connected(graph, start, target) using BFS — return True if target is reachable from start. 
from collections import deque

def is_connected(graph, start, target):
    visited = set([start])
    queue = deque([start])

    while queue:
        node = queue.popleft()
        if node == target:
            return True
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

    return False

graph = {
    "A": ["B", "C"], "B": ["A", "D"], "C": ["A", "D"],
    "D": ["B", "C", "E"], "E": ["D"], "F": []
}

print(is_connected(graph, "A", "E"))   # True
print(is_connected(graph, "A", "F"))   # False — F is isolated

✍️ Chapter Summary

  • Graph — nodes (vertices) connected by edges, directed or undirected
  • Adjacency list — a dict mapping each node to its neighbors
  • BFS — queue-based, explores level by level, finds shortest path
  • DFS — stack/recursion-based, explores one path fully before backtracking
  • Always track visited nodes to avoid infinite loops on cycles
