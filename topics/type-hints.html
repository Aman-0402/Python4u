🏷️ Chapter 24

Type Hints & the typing Module

Tell readers (and tools) what type of data a function expects and returns — without changing how Python runs.

🏷️

🏷️ Labels, Not Rules

Python stays dynamically typed — type hints don't stop wrong types at runtime. They're labels that help humans and editors catch mistakes before running the code.

⚡ 1. Basic Type Hints

Without hints

def add(a, b):
    return a + b

Works, but unclear: are a and b numbers? Strings? Lists?

With hints

def add(a: int, b: int) -> int:
    return a + b

print(add(3, 5))
8

a: int and b: int say the parameters should be integers. -> int says the function returns an integer.

⚠️ Type hints are NOT enforced at runtime. add("hi", "bye") still runs and returns "hibye" — hints are documentation + tooling, not a type checker built into Python itself.

📦 2. Variable Hints

student_name: str = "Ravi"
age: int = 21
gpa: float = 8.7
is_enrolled: bool = True

📚 3. Collections — list, dict, tuple

def average_marks(marks: list[int]) -> float:
    return sum(marks) / len(marks)

def student_grades() -> dict[str, int]:
    return {"Ravi": 78, "Sita": 92}

print(average_marks([70, 80, 90]))
print(student_grades())
80.0 {'Ravi': 78, 'Sita': 92}
HintMeaning
list[int]A list containing integers
dict[str, int]A dict with string keys, integer values
tuple[int, str]A tuple: first item int, second item str

🔀 4. Optional and Union Types

Use | (Python 3.10+) or Optional to say a value could be one of several types, or missing.

def find_student(student_id: int) -> str | None:
    students = {1: "Ravi", 2: "Sita"}
    return students.get(student_id)   # returns None if not found

print(find_student(1))   # Ravi
print(find_student(99))  # None
Ravi None

str | None means "returns a string, or possibly nothing."

🛠️ 5. Checking Hints With mypy

Type hints become useful when a checker like mypy reads your code and flags mismatches before you run it.

# bad_example.py
def add(a: int, b: int) -> int:
    return a + b

add("3", "5")   # wrong types passed in
# terminal
$ mypy bad_example.py
bad_example.py:4: error: Argument 1 to "add" has incompatible type "str"; expected "int"
💡 Install with pip install mypy, then run mypy your_file.py to catch type mismatches before they become runtime bugs.

✍️ Chapter Summary

  • param: type hints a parameter's expected type
  • -> type hints the return type
  • list[int], dict[str, int] — hint collection contents
  • str | None — hints a value could be missing
  • Hints are checked by tools like mypy, not by Python itself
