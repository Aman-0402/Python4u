🕸️ Turning Web Pages Into Data

A web page is just HTML text. requests downloads that text, and BeautifulSoup parses it so you can search for specific tags, classes, and content.

⚡ 1. Fetching a Page

# pip install requests

import requests

response = requests.get("https://example.com")

print(response.status_code)   # 200 = success
print(response.text[:100])    # first 100 characters of HTML
200 <!doctype html> <html> <head> <title>Example Domain</title>
Status CodeMeaning
200OK — request succeeded
404Not Found
403Forbidden — access denied
500Server error

⚠️ Handling Request Failures

Scraping means hitting servers you don't control — timeouts, blocks, and dead links are normal. Never assume the request worked.

import requests

try:
    response = requests.get("https://example.com/books", timeout=5)
    response.raise_for_status()   # raises an error for 4xx/5xx status codes
except requests.exceptions.Timeout:
    print("Server took too long to respond.")
except requests.exceptions.ConnectionError:
    print("Could not reach the site — check the URL or your connection.")
except requests.exceptions.HTTPError as e:
    print(f"Site returned an error: {e}")
else:
    print("Page fetched successfully")
⚠️ Without timeout=, a hanging server can freeze your script forever. Without raise_for_status(), a 404 page's HTML gets parsed as if it were real data — leading to confusing empty results instead of a clear error.

🍜 2. Parsing HTML — BeautifulSoup

# pip install beautifulsoup4

from bs4 import BeautifulSoup

html = """
<html>
  <body>
    <h1>Book Store</h1>
    <p class="price">₹450</p>
    <p class="price">₹899</p>
  </body>
</html>
"""

soup = BeautifulSoup(html, "html.parser")

title = soup.find("h1").text
print(title)
Book Store

🔎 3. Finding Multiple Elements

from bs4 import BeautifulSoup

html = """
<div>
  <p class="price">₹450</p>
  <p class="price">₹899</p>
  <p class="price">₹120</p>
</div>
"""

soup = BeautifulSoup(html, "html.parser")
prices = soup.find_all("p", class_="price")

for p in prices:
    print(p.text)
₹450 ₹899 ₹120

find() returns the first match. find_all() returns every match as a list.

🛠️ 4. Putting It Together — Real Scrape

import requests
from bs4 import BeautifulSoup

response = requests.get("https://example.com/books")
soup = BeautifulSoup(response.text, "html.parser")

books = []
for item in soup.find_all("div", class_="book-card"):
    title = item.find("h2").text.strip()
    price = item.find("span", class_="price").text.strip()
    books.append({"title": title, "price": price})

print(books)
⚠️ Always check a site's robots.txt and terms of service before scraping. Add delays between requests (time.sleep()) so you don't overload the server.

🎯 5. .select() — CSS Selectors Instead of find/find_all

If you know CSS selectors (from HTML/CSS work), .select() is often faster to write than chained find() calls — especially for nested or specific elements.

from bs4 import BeautifulSoup

html = """
<div class="book-card">
  <h2 class="title">Python Basics</h2>
  <span class="price">₹450</span>
</div>
<div class="book-card">
  <h2 class="title">Advanced Python</h2>
  <span class="price">₹899</span>
</div>
"""

soup = BeautifulSoup(html, "html.parser")

titles = soup.select("div.book-card h2.title")   # tag.class syntax, just like CSS
print([t.text for t in titles])

first_price = soup.select_one(".price")           # first match only
print(first_price.text)
['Python Basics', 'Advanced Python'] ₹450
SelectorMatches
"div"Every <div> tag
".price"Every element with class="price"
"#main"The element with id="main"
"div.book-card h2"Any <h2> nested inside a div with class book-card

select() returns a list (like find_all()), select_one() returns a single element (like find()).

🚧 6. The JavaScript Trap

requests only downloads the raw HTML the server sends — it does not run any JavaScript. Many modern sites load their real content after the page loads, using JavaScript. Scraping those with just requests + BeautifulSoup silently returns an almost-empty page.

import requests
from bs4 import BeautifulSoup

response = requests.get("https://a-js-heavy-site.example.com")
soup = BeautifulSoup(response.text, "html.parser")

print(soup.find("div", id="app"))   # often just an empty shell, e.g. <div id="app"></div>
# The real content was inserted by JavaScript AFTER the page loaded —
# requests never saw it because it doesn't execute JS.
⚠️ If your scraper finds nothing where the browser clearly shows data, this is almost always why. The fix is a browser-automation tool like Selenium or Playwright, which actually opens a real browser, waits for JavaScript to run, then reads the final HTML.

📤 7. Getting Data From an API Instead

Many sites offer a JSON API — cleaner and more reliable than scraping HTML when it's available (covered in the Web APIs chapter).

import requests

response = requests.get("https://api.example.com/books")
data = response.json()   # parses JSON directly into a dict/list

print(data)

🚀 Challenge: Given this HTML string, extract all quote texts into a list. 
html = """
<div>
  <span class="quote">Stay hungry, stay foolish</span>
  <span class="quote">Code is poetry</span>
</div>
"""
from bs4 import BeautifulSoup

soup = BeautifulSoup(html, "html.parser")
quotes = [q.text for q in soup.find_all("span", class_="quote")]
