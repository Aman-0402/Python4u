Functional Tools — lambda, map, filter, reduce

Short throwaway functions and quick ways to transform or filter data without writing loops.

λ

λ Small Functions, Big Reuse

Sometimes you need a tiny one-line function just to pass somewhere else. Python has a compact syntax for that, plus tools that use it to transform lists.

⚡ 1. lambda — Anonymous Functions

Normal function

def square(x):
    return x * x

print(square(5))
25

Same thing as a lambda

square = lambda x: x * x
print(square(5))
25

lambda arguments: expression — no def, no return, always a single expression.

💡 Use lambda for short, throwaway functions passed as arguments. For anything longer than one line, write a normal def function.

🔄 2. map() — Transform Every Item

prices = [100, 250, 75, 500]
with_tax = list(map(lambda p: p * 1.18, prices))

print(with_tax)
[118.0, 295.0, 88.5, 590.0]

map(function, iterable) applies the function to every item and returns a map object — wrap in list() to see results.

🔎 3. filter() — Keep Only Matching Items

marks = [55, 90, 42, 30, 78, 61]
passed = list(filter(lambda m: m >= 40, marks))

print(passed)
[55, 90, 42, 78, 61]

filter(function, iterable) keeps only items where the function returns True.

ℹ️ The same result can be written as a list comprehension: [m for m in marks if m >= 40] — comprehensions are usually preferred in modern Python for readability.

➕ 4. reduce() — Combine All Items Into One

from functools import reduce

cart = [250, 40, 999, 15, 620]
total = reduce(lambda acc, price: acc + price, cart)

print(total)
1924

reduce(function, iterable) repeatedly applies the function, carrying an accumulator, until one final value remains.

📊 5. Sorting With a Key Function

students = [("Ravi", 78), ("Sita", 92), ("Amit", 65)]

by_score = sorted(students, key=lambda s: s[1], reverse=True)
print(by_score)
[('Sita', 92), ('Ravi', 78), ('Amit', 65)]

names = ["ravi", "SITA", "Amit"]
fixed = list(map(lambda n: n.capitalize(), names))

✍️ Chapter Summary

  • lambda args: expr — short, unnamed, single-expression function
  • map(func, iterable) — transform every item
  • filter(func, iterable) — keep items where func returns True
  • reduce(func, iterable) — combine all items into one value
  • sorted(data, key=lambda x: ...) — sort by a custom rule
