🥞 Chapter 38

Stack & Queue

Two simple ways to store items where the ORDER you remove them matters as much as what's stored.

🥞

🥞 Last In vs First In

A stack and a queue hold the exact same kind of data — the only difference is which end you're allowed to remove from.

🥞 1. Stack — LIFO (Last In, First Out)

Think of a stack of plates: you add to the top, and you take from the top. The last plate you put down is the first one you pick back up.

stack = []

stack.append("Page A")   # visit page A
stack.append("Page B")   # visit page B
stack.append("Page C")   # visit page C

print(stack)

last_page = stack.pop()  # go "back" — removes from the END
print(f"Went back from: {last_page}")
print(stack)
['Page A', 'Page B', 'Page C'] Went back from: Page C ['Page A', 'Page B']

A regular Python list is already a perfectly good stack — append() to push, pop() to pop, both O(1) at the end.

🌐 Real Use: Browser "Back" Button

Every page you visit gets pushed onto a stack. Clicking "Back" pops the most recent page off — exactly LIFO behavior. Undo/redo in editors works the same way.

🚶 2. Queue — FIFO (First In, First Out)

Think of a line at a ticket counter: whoever joined first gets served first. New people join the back; service happens from the front.

from collections import deque

queue = deque()

queue.append("Ravi")   # joins the back of the line
queue.append("Sita")
queue.append("Amit")

print(queue)

next_person = queue.popleft()   # serve from the FRONT
print(f"Now serving: {next_person}")
print(queue)
deque(['Ravi', 'Sita', 'Amit']) Now serving: Ravi deque(['Sita', 'Amit'])
⚠️ Don't use a plain list with .pop(0) for a queue — removing from the front of a list is O(n) because every remaining item has to shift over. collections.deque is built for this: both ends are O(1).

✅ 4. Real Example — Balanced Brackets (Stack)

A classic stack use: checking that every opening bracket has a matching closing one, in the right order.

def is_balanced(text):
    stack = []
    pairs = {")": "(", "]": "[", "}": "{"}

    for char in text:
        if char in "([{":
            stack.append(char)
        elif char in ")]}":
            if not stack or stack.pop() != pairs[char]:
                return False

    return len(stack) == 0   # nothing left un-closed

print(is_balanced("(a + [b * c])"))   # True
print(is_balanced("(a + [b * c)"))    # False — mismatched
True False

Every open bracket gets pushed. Every close bracket must match the most recently pushed open bracket — exactly the LIFO behavior a stack provides.

🎫 5. Real Example — Task Queue (Queue)

from collections import deque

print_queue = deque()

print_queue.append("Document1.pdf")
print_queue.append("Document2.pdf")
print_queue.append("Document3.pdf")

while print_queue:
    job = print_queue.popleft()
    print(f"Printing: {job}")
Printing: Document1.pdf Printing: Document2.pdf Printing: Document3.pdf

Jobs print in the order they were submitted — fair, first-come-first-served processing.

🚀 Challenge: Use a stack to reverse a string (push every character, then pop them all off). 
def reverse_string(text):
    stack = list(text)     # push all characters
    reversed_text = ""
    while stack:
        reversed_text += stack.pop()   # pop from the end, one at a time
    return reversed_text

print(reverse_string("python"))   # nohtyp

✍️ Chapter Summary

  • Stack — LIFO, use a list with append()/pop()
  • Queue — FIFO, use collections.deque with append()/popleft()
  • Stack: browser back button, undo, bracket matching
  • Queue: print jobs, task scheduling, anything "first come, first served"
