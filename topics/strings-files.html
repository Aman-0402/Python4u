📄 Strings & Files

Strings are everywhere. Files save data forever. Master both and you'll never say "wait, I forgot what we typed" like Dory ever again.

📹 1. What is a String?

Sequence of characters. In Python: immutable — can't change individual characters after creation. Can use single ' or double " quotes.

🐱 Tom's Threat Letters to Jerry

Each letter Tom writes is a string. He can read it, copy it, reverse it — but if he wants to change a word, he has to write a whole new letter. Strings are immutable like that.

threat = "Dear Jerry, your cheese days are numbered."
greeting = 'Signed, Tom (who will definitely catch you this time)'
multiline = """Tom's Log Entry #347:
Tried the rocket skates again.
Result: another wall. Classic."""

print(len(threat))     # 43  (characters including spaces)
print(type(threat))    # <class 'str'>
43 <class 'str'>

💡 Slice syntax: string[start : end : step] — start inclusive, end exclusive. Default step = 1.

⚡ 4. f-Strings — Clean String Formatting

f-strings (Python 3.6+) embed variables directly in strings. No more ugly + concatenation.

name = "Bugs Bunny"
iq   = 200
prey = "Elmer Fudd"

# Old way (ugly, error-prone)
print("Name: " + name + ", IQ: " + str(iq))

# f-string (clean, readable)
print(f"Name: {name}, IQ: {iq}")
print(f"{name} outwits {prey} {iq // 10} times per episode.")
Name: Bugs Bunny, IQ: 200 Name: Bugs Bunny, IQ: 200 Bugs Bunny outwits Elmer Fudd 20 times per episode.

📈 f-string formatting tricks

pi = 3.14159
price = 42000.5

print(f"Pi to 2 decimals: {pi:.2f}")          # 3.14
print(f"Price: ₹{price:,.0f}")                # ₹42,001
print(f"Right-aligned: {'Scooby':>10}")       #      Scooby
print(f"Padded zeros: {7:05d}")               # 00007
Pi to 2 decimals: 3.14 Price: ₹42,001 Right-aligned: Scooby Padded zeros: 00007

📂 5. File I/O — Reading & Writing Files

Programs die, data doesn't. Files let you persist data beyond runtime. Sherlock Holmes doesn't keep every case in his head — he writes notes.

📝 File Modes

📄 Writing — Sherlock's Case Notes

with open("case_notes.txt", "w") as f:
    f.write("Case: The Missing Cheese\n")
    f.write("Suspect: Tom (paw prints everywhere)\n")
    f.write("Verdict: Guilty — caught on kitchen CCTV\n")

print("Notes saved.")
Notes saved.
💡 with open(...) as f: automatically closes file when block exits — even on error. Always use with. Never open() without it.

📖 Reading — Indiana Jones reads the scroll

🔧 7. Practical: Scooby-Doo Case Logger

def log_mystery(filename, location, villain, solved):
    status = "SOLVED" if solved else "ONGOING"
    entry = f"[{status}] {location} — {villain}\n"
    with open(filename, "a") as f:
        f.write(entry)
    print(f"Logged: {entry.strip()}")

def read_all_cases(filename):
    try:
        with open(filename, "r") as f:
            print("=== Mystery Log ===")
            for line in f:
                print(line.strip())
    except FileNotFoundError:
        print("No cases logged yet!")

# Log some mysteries
log_mystery("mystery_log.txt", "Haunted Fairground", "Old Henderson", True)
log_mystery("mystery_log.txt", "Sunken Ship",        "Captain Ghost",  True)
log_mystery("mystery_log.txt", "Abandoned Mansion",  "Unknown",        False)

# Read them back
read_all_cases("mystery_log.txt")

def is_palindrome(s):
    cleaned = s.lower().replace(" ", "")
    return cleaned == cleaned[::-1]

for w in words:
    result = "IS" if is_palindrome(w) else "is NOT"
