🧪 Chapter 26

Testing — unittest & pytest

Write code that checks your code, so bugs get caught automatically instead of by users.

🧪

🧪 Trust, But Verify

A test is a small piece of code that calls your function and checks the result is what you expect. Run all your tests in seconds, anytime you change code.

⚡ 1. The Function We'll Test

# calculator.py
def add(a, b):
    return a + b

def divide(a, b):
    if b == 0:
        raise ValueError("Cannot divide by zero")
    return a / b

🐍 2. Testing with unittest (built-in)

# test_calculator.py
import unittest
from calculator import add, divide

class TestCalculator(unittest.TestCase):

    def test_add(self):
        self.assertEqual(add(2, 3), 5)

    def test_add_negative(self):
        self.assertEqual(add(-1, -1), -2)

    def test_divide(self):
        self.assertEqual(divide(10, 2), 5)

    def test_divide_by_zero(self):
        with self.assertRaises(ValueError):
            divide(10, 0)

if __name__ == "__main__":
    unittest.main()
# terminal
$ python -m unittest test_calculator.py -v

🚀 3. Testing with pytest (simpler syntax)

pytest is a popular third-party library — plain functions with plain assert, no class required.

# pip install pytest

# test_calculator.py
from calculator import add, divide
import pytest

def test_add():
    assert add(2, 3) == 5

def test_add_negative():
    assert add(-1, -1) == -2

def test_divide():
    assert divide(10, 2) == 5

def test_divide_by_zero():
    with pytest.raises(ValueError):
        divide(10, 0)
# terminal
$ pytest test_calculator.py -v
test_calculator.py::test_add PASSED test_calculator.py::test_add_negative PASSED test_calculator.py::test_divide PASSED test_calculator.py::test_divide_by_zero PASSED 4 passed in 0.01s

🔁 4. Fixtures — Reusable Setup

When multiple tests need the same starting data, a fixture builds it once per test.

import pytest

@pytest.fixture
def sample_students():
    return {"Ravi": 78, "Sita": 92, "Amit": 65}

def test_student_count(sample_students):
    assert len(sample_students) == 3

def test_top_student(sample_students):
    top = max(sample_students, key=sample_students.get)
    assert top == "Sita"
💡 Each test function that takes sample_students as a parameter gets a fresh copy — tests don't accidentally affect each other.

📊 5. Why Bother Testing?

Without testsWith tests
Manually re-check everything after a changeRun one command, get a pass/fail report
Bugs found by users in productionBugs found before you even commit
