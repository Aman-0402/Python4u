🔍 Pattern Matching for Text

A regular expression (regex) is a mini-language for describing text patterns — "a word, then digits, then an @ sign" — instead of writing manual loops.

⚡ 1. Basic Search

import re

text = "My phone number is 98765 43210"
match = re.search(r"\d+", text)

print(match.group())
98765

\d+ means "one or more digits." re.search() finds the first match anywhere in the string.

PatternMeaning
\dAny digit (0-9)
\wAny letter, digit, or underscore
\sAny whitespace (space, tab)
.Any single character
+One or more of the previous
*Zero or more of the previous
?Zero or one of the previous (optional)
^Start of string
$End of string

✅ 2. Validating Input — Email Check

import re

def is_valid_email(email):
    pattern = r"^[\w.]+@[\w]+\.[a-z]+$"
    return bool(re.match(pattern, email))

print(is_valid_email("student@example.com"))   # True
print(is_valid_email("not-an-email"))          # False
True False
💡 re.match() checks the pattern from the start of the string. re.fullmatch() requires the whole string to match. re.search() looks anywhere.

🔎 3. Finding All Matches

import re

text = "Contact: ravi@mail.com, sita@school.org, admin@site.net"
emails = re.findall(r"[\w.]+@[\w.]+", text)

print(emails)
['ravi@mail.com', 'sita@school.org', 'admin@site.net']

✂️ 4. Replacing Text

import re

text = "Call 9876543210 or 8765432109 for support"
masked = re.sub(r"\d{10}", "**PHONE HIDDEN**", text)

print(masked)
Call **PHONE HIDDEN** or **PHONE HIDDEN** for support

📦 5. Groups — Extracting Parts

Parentheses ( ) capture parts of the match separately.

import re

log_line = "2024-03-15 ERROR Database connection failed"
match = re.match(r"(\d{4}-\d{2}-\d{2}) (\w+) (.+)", log_line)

print(match.group(1))   # date
print(match.group(2))   # level
print(match.group(3))   # message
2024-03-15 ERROR Database connection failed

🚀 Challenge: Write a function extract_hashtags(text) that returns all hashtags (words starting with #) from a sentence. 
import re

def extract_hashtags(text):
    return re.findall(r"#\w+", text)

print(extract_hashtags("Loving #python and #coding today! #100DaysOfCode"))
# ['#python', '#coding', '#100DaysOfCode']

✍️ Chapter Summary

  • re.search() — find first match anywhere
  • re.match() — match from the start of the string
  • re.findall() — return every match as a list
  • re.sub() — replace matches with new text
  • ( ) groups let you pull out specific parts of a match
