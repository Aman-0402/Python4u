🔍 Pattern Matching for Text

A regular expression (regex) is a mini-language for describing text patterns — "a word, then digits, then an @ sign" — instead of writing manual loops.

⚡ 1. Basic Search

import re

text = "My phone number is 98765 43210"
match = re.search(r"\d+", text)

print(match.group())
98765

\d+ means "one or more digits." re.search() finds the first match anywhere in the string.

PatternMeaning
\dAny digit (0-9)
\wAny letter, digit, or underscore
\sAny whitespace (space, tab)
.Any single character
+One or more of the previous
*Zero or more of the previous
?Zero or one of the previous (optional)
^Start of string
$End of string

✅ 2. Validating Input — Email Check

import re

def is_valid_email(email):
    pattern = r"^[\w.]+@[\w]+\.[a-z]+$"
    return bool(re.match(pattern, email))

print(is_valid_email("student@example.com"))   # True
print(is_valid_email("not-an-email"))          # False
True False
💡 re.match() checks the pattern from the start of the string. re.fullmatch() requires the whole string to match. re.search() looks anywhere.

🔎 3. Finding All Matches

import re

text = "Contact: ravi@mail.com, sita@school.org, admin@site.net"
emails = re.findall(r"[\w.]+@[\w.]+", text)

print(emails)
['ravi@mail.com', 'sita@school.org', 'admin@site.net']

✂️ 4. Replacing Text

import re

text = "Call 9876543210 or 8765432109 for support"
masked = re.sub(r"\d{10}", "**PHONE HIDDEN**", text)

print(masked)
Call **PHONE HIDDEN** or **PHONE HIDDEN** for support

📦 5. Groups — Extracting Parts

Parentheses ( ) capture parts of the match separately.

import re

log_line = "2024-03-15 ERROR Database connection failed"
match = re.match(r"(\d{4}-\d{2}-\d{2}) (\w+) (.+)", log_line)

print(match.group(1))   # date
print(match.group(2))   # level
print(match.group(3))   # message
2024-03-15 ERROR Database connection failed

Named groups — clearer than group(1), group(2)

match = re.match(r"(?P\d{4}-\d{2}-\d{2}) (?P\w+) (?P.+)", log_line)

print(match.group("date"))
print(match.group("level"))
print(match["message"])   # subscript syntax also works
2024-03-15 ERROR Database connection failed

(?P<name>...) names a group — much easier to read than counting parentheses when there are several groups.

🧩 6. Character Classes — Matching a Set of Characters

Square brackets [ ] mean "match one character from this set." Great when \d/\w are too broad or too narrow.

import re

# [aeiou] = match any single vowel
vowels = re.findall(r"[aeiou]", "Hello World")
print(vowels)

# [^0-9] = match anything that is NOT a digit (^ inside [] means "not")
non_digits = re.findall(r"[^0-9]", "abc123xyz")
print(non_digits)

# [A-Z] = match any single uppercase letter
caps = re.findall(r"[A-Z]", "Hello World From Python")
print(caps)
['e', 'o', 'o'] ['a', 'b', 'c', 'x', 'y', 'z'] ['H', 'W', 'F', 'P']
PatternMeaning
[abc]Match a, b, or c
[a-z]Match any lowercase letter
[^abc]Match anything EXCEPT a, b, or c
[0-9A-Fa-f]Match a hex digit (combine multiple ranges)

🔢 7. Quantifier Ranges & Word Boundaries

import re

# {n,m} = between n and m repeats
print(re.findall(r"\d{2,4}", "1 12 123 12345"))

# \b = word boundary — matches at the edge of a word, matches nothing itself
print(re.findall(r"\bcat\b", "cat category concatenate cat"))
['12', '123', '1234'] ['cat', 'cat']

Without \b, re.findall(r"cat", ...) would also match "cat" inside "category" and "concatenate" — \b makes sure it's a whole word, not just a substring.

PatternMeaning
{3}Exactly 3 repeats
{2,4}Between 2 and 4 repeats
{2,}2 or more repeats, no upper limit
\bWord boundary (start/end of a word)

🎣 8. Greedy vs Non-Greedy Matching

By default, * and + are greedy — they grab as much text as possible. Add ? to make them non-greedy — grab as little as possible.

import re

html = "<b>Bold</b> and <i>Italic</i>"

greedy = re.findall(r"<.+>", html)
print(greedy)

non_greedy = re.findall(r"<.+?>", html)
print(non_greedy)
['Bold and Italic'] ['', '', '', '']

Greedy .+ stretched from the very first < to the very last > — matching way more than intended. Non-greedy .+? stops at the first > it finds, giving four separate correct matches.

♻️ 9. re.compile() — Reusing a Pattern

If you use the same pattern many times (e.g. validating thousands of emails in a loop), compile it once instead of re-parsing the pattern text every call.

import re

email_pattern = re.compile(r"^[\w.]+@[\w]+\.[a-z]+$")

emails = ["ravi@mail.com", "not-an-email", "sita@school.org"]
for email in emails:
    if email_pattern.match(email):
        print(f"{email}: valid")
    else:
        print(f"{email}: invalid")
ravi@mail.com: valid not-an-email: invalid sita@school.org: valid
💡 re.compile(pattern) returns a pattern object with the same methods (.match(), .search(), .findall()) — faster when reused, and it's a good place to put a pattern you'll reference more than once.

🚀 Challenge: Write a function extract_hashtags(text) that returns all hashtags (words starting with #) from a sentence. 
import re

def extract_hashtags(text):
    return re.findall(r"#\w+", text)

print(extract_hashtags("Loving #python and #coding today! #100DaysOfCode"))
# ['#python', '#coding', '#100DaysOfCode']

  • re.findall() — return every match as a list
  • re.sub() — replace matches with new text
  • ( ) groups let you pull out specific parts of a match
