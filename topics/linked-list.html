🔗 Chapter 39

Linked List

A chain of nodes, each pointing to the next — a different way to store a sequence than a Python list.

🔗

🔗 A Chain, Not a Row

A Python list stores items in one continuous memory block. A linked list scatters items anywhere in memory, connected by pointers — trading fast random access for fast insertion.

⚡ 1. Why Linked Lists Exist

A Python list is actually a dynamic array — inserting at the front means shifting every other item over, which is O(n). A linked list can insert at the front in O(1) — it just rewires one pointer, nothing moves.

OperationPython list (array)Linked list
Access item by indexO(1)O(n) — must walk from the start
Insert/delete at frontO(n) — shifts everythingO(1) — just rewires a pointer
Insert/delete at endO(1) (amortized)O(n) unless you track the tail
💡 In everyday Python code, use the built-in list — it's fast and simple for almost everything. Linked lists matter for understanding how data structures trade off different operations, and they show up in interviews and lower-level systems code.

🧱 2. Building a Node

Each node holds a value and a pointer (next) to the next node in the chain. The last node points to None.

class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

Visually: 10 → 20 → 30 → None

🔗 3. Building the Linked List Class

class Node:
    def __init__(self, value):
        self.value = value
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None    # points to the first node

    def append(self, value):
        new_node = Node(value)
        if self.head is None:
            self.head = new_node
            return
        current = self.head
        while current.next:          # walk to the last node
            current = current.next
        current.next = new_node      # attach the new node at the end

    def print_list(self):
        current = self.head
        values = []
        while current:
            values.append(str(current.value))
            current = current.next
        print(" -> ".join(values))

ll = LinkedList()
ll.append(10)
ll.append(20)
ll.append(30)
ll.print_list()
10 -> 20 -> 30

➕ 4. Inserting at the Front — O(1)

class LinkedList:
    def __init__(self):
        self.head = None

    def prepend(self, value):
        new_node = Node(value)
        new_node.next = self.head    # new node points to old first node
        self.head = new_node         # new node becomes the first node

ll = LinkedList()
ll.append(20)
ll.append(30)
ll.prepend(10)
ll.print_list()
10 -> 20 -> 30

No shifting happened — just two pointer assignments, regardless of how long the list is. Compare that to python_list.insert(0, value), which is O(n) because everything after index 0 has to shift right.

🗑️ 5. Deleting a Node

class LinkedList:
    def __init__(self):
        self.head = None

    def delete(self, value):
        if self.head is None:
            return

        if self.head.value == value:      # deleting the first node
            self.head = self.head.next
            return

        current = self.head
        while current.next:
            if current.next.value == value:
                current.next = current.next.next   # skip over the deleted node
                return
            current = current.next

ll = LinkedList()
ll.append(10)
ll.append(20)
ll.append(30)
ll.delete(20)
ll.print_list()
10 -> 30

Deleting means re-pointing current.next to skip the target node — the node itself is simply abandoned (Python's garbage collector cleans it up), nothing needs to shift.

🚀 Challenge: Add a method find(value) to LinkedList that returns True if the value exists in the list, False otherwise. 
class LinkedList:
    def __init__(self):
        self.head = None

    def append(self, value):
        new_node = Node(value)
        if self.head is None:
            self.head = new_node
            return
        current = self.head
        while current.next:
            current = current.next
        current.next = new_node

    def find(self, value):
        current = self.head
        while current:
            if current.value == value:
                return True
            current = current.next
        return False

ll = LinkedList()
ll.append(10)
ll.append(20)
print(ll.find(20))   # True
print(ll.find(99))   # False

✍️ Chapter Summary

  • Linked list — a chain of nodes, each pointing to the next
  • Fast insert/delete at the front — O(1), no shifting
  • Slow random access — O(n), must walk from the head
  • Python's built-in list is an array — opposite tradeoffs
