List []

Ordered, mutable, allows duplicates. The shopping bag — add/remove freely.

Ordered, immutable. Bedrock laws — carved in stone, can't change.

🎉

Unordered, unique elements only. VIP list — no duplicates at the door.

Key-value pairs. Gadget lookup — every name maps to its power.

list 1. List — Jerry's Cheese Heist

Ordered, mutable, allows duplicates. Jerry updates his cheese stash all the time. That's a list.

🐛 Jerry's Cheese Inventory

Jerry keeps a list of stolen cheeses. Adds new ones, removes eaten ones, sorts by size, counts the total. Tom's list of failed traps is also a list — very, very long.

jerry_cheeses = ["cheddar", "gouda", "brie", "swiss", "cheddar"]

print(jerry_cheeses[0])      # cheddar  (0-indexed)
print(jerry_cheeses[-1])     # cheddar  (last item)
print(len(jerry_cheeses))    # 5
cheddar cheddar 5

🔄 Slicing — Take a piece like Jerry

cheeses = ["cheddar", "gouda", "brie", "swiss", "parmesan"]
print(cheeses[1:4])    # ['gouda', 'brie', 'swiss']
print(cheeses[:3])     # ['cheddar', 'gouda', 'brie']
print(cheeses[-2:])    # ['swiss', 'parmesan']
print(cheeses[::2])    # ['cheddar', 'brie', 'parmesan']  (every 2nd)
['gouda', 'brie', 'swiss'] ['cheddar', 'gouda', 'brie'] ['swiss', 'parmesan'] ['cheddar', 'brie', 'parmesan']

⚡ Tom's Trap Log — Methods in action

traps = ["bucket drop", "rocket skates", "anvil ceiling"]

traps.append("fake tunnel painted on wall")    # add
traps.insert(0, "giant mousetrap")             # insert at front
traps.remove("rocket skates")                  # remove by value
popped = traps.pop()                           # remove last
traps.sort()                                   # alphabetical

print(traps)
print(f"Popped trap: {popped}")
print(f"Total remaining traps: {len(traps)}")
['anvil ceiling', 'bucket drop', 'giant mousetrap'] Popped trap: fake tunnel painted on wall Total remaining traps: 3

⚡ List Comprehension — Power move

# SpongeBob needs prices above 10
menu_prices = [5, 12, 3, 8, 15, 20, 2]
expensive = [p for p in menu_prices if p > 10]
print(expensive)   # [12, 15, 20]

# Square each price (Gary tax)

[12, 15, 20] [24, 30, 40]

tuple 2. Tuple — Bedrock Laws

Ordered, immutable. Can't add, remove, or change items. Like laws of Bedrock — written in stone. Fred Flintstone tried to update the mammoth migration schedule. TypeError.

bedrock_laws = ("thou shalt not steal mammoth", "work 9 to 5", "YABBA DABBA DOO")

print(bedrock_laws[2])          # YABBA DABBA DOO
print(len(bedrock_laws))        # 3

# bedrock_laws[0] = "something else"  ← TypeError: tuple is immutable
YABBA DABBA DOO 3

⚠️ The Single-Item Trap

not_a_tuple = ("yabba")         # just a string in parentheses

print(type(not_a_tuple))        # <class 'str'>

set 3. Set — The VIP Door Policy

Unordered. Unique elements only. No duplicates, no indexing. Like the Looney Tunes VIP party — each character gets in once. Duplicate Daffy at the door? Kicked out.

looney_vip = {"Bugs Bunny", "Daffy Duck", "Bugs Bunny", "Tweety", "Bugs Bunny"}
print(looney_vip)      # Bugs admitted once, duplicates dropped
{'Bugs Bunny', 'Daffy Duck', 'Tweety'}
⚠️ {} creates empty dict, not set! For empty set use set().

📈 Set Operations — Venn diagram in code

team_bugs = {"Bugs Bunny", "Tweety", "Road Runner", "Speedy Gonzales"}
team_daffy = {"Daffy Duck", "Tweety", "Yosemite Sam", "Speedy Gonzales"}

print("Union (all members):")
print(team_bugs | team_daffy)             # all unique names

print("\nIntersection (shared members):")
print(team_bugs & team_daffy)             # in BOTH teams

print("\nDifference (only in Bugs' team):")
print(team_bugs - team_daffy)             # Bugs' exclusives

print("\nSymmetric difference (not shared):")
print(team_bugs ^ team_daffy)             # in one but NOT both
Union (all members): {'Bugs Bunny', 'Tweety', 'Road Runner', 'Speedy Gonzales', 'Daffy Duck', 'Yosemite Sam'} Intersection (shared members): {'Tweety', 'Speedy Gonzales'} Difference (only in Bugs' team): {'Bugs Bunny', 'Road Runner'} Symmetric difference (not shared): {'Bugs Bunny', 'Road Runner', 'Daffy Duck', 'Yosemite Sam'}

dict 4. Dictionary — Inspector Gadget's Database

Key-value pairs. Access value by key, not position. Like Inspector Gadget's gadget lookup — say the name, get the tool. "Go-Go Gadget Copter!" → key "copter" → value "hat helicopter".

gadgets = {
    "copter":    "hat helicopter",
    "arm":       "extending mechanical arm",
    "binoculars":"binocular eyes (slightly terrifying)",
    "phone":     "shoe phone (classic)",
}

print(gadgets["copter"])
print(gadgets.get("laser", "DR. CLAW STOLE IT"))    # safe access with default
hat helicopter DR. CLAW STOLE IT

🔎 Scooby-Doo Mystery Database

mysteries = {
    "Haunted Mansion":    {"villain": "Old Jenkins", "solved": True},
    "Ghost Ship":         {"villain": "Captain Reynolds", "solved": True},

⚡ Dictionary Comprehension

# Bugs Bunny's IQ scores: name → IQ squared (because why not)
characters = ["Bugs", "Daffy", "Tweety", "Elmer"]
iqs        = [200, 80, 140, 30]

iq_map = {name: iq for name, iq in zip(characters, iqs)}
print(iq_map)

# Filter: only smart ones (IQ > 100)
smart = {k: v for k, v in iq_map.items() if v > 100}
print(smart)
{'Bugs': 200, 'Daffy': 80, 'Tweety': 140, 'Elmer': 30} {'Bugs': 200, 'Tweety': 140}

🔄 Converting Between Types

jerry_list = [1, 2, 2, 3, 3, 3]

as_set   = set(jerry_list)       # {1, 2, 3}  — duplicates gone
as_tuple = tuple(jerry_list)     # (1, 2, 2, 3, 3, 3)  — immutable

print(as_set)
print(as_tuple)
print(list(as_set))              # back to list from set
{1, 2, 3} (1, 2, 2, 3, 3, 3) [1, 2, 3]

🚀 Challenge 3: The Great Gadget Inventory
Inspector Gadget list: ["copter","arm","copter","binoculars","phone","arm","arm"]. Use .count() to find most-used gadget. Use comprehension to build dict of gadget → use count. 
gadget_log = ["copter", "arm", "copter", "binoculars", "phone", "arm", "arm"]

usage = {g: gadget_log.count(g) for g in set(gadget_log)}
print("Gadget usage:")
for gadget, count in sorted(usage.items(), key=lambda x: -x[1]):
    print(f"  {gadget}: {count}x")
