Magic / Dunder Methods

Special methods (like __str__, __len__) that let your own classes work with Python's built-in functions and operators.

✨

✨ Making Your Objects Behave Like Built-ins

"Dunder" = double underscore. These methods are never called directly — Python calls them automatically when you use print(), len(), +, == and more on your objects.

🖨️ 1. __str__ — Readable Printing

Without it

class Student:
    def __init__(self, name, grade):
        self.name = name
        self.grade = grade

s = Student("Ravi", "A")
print(s)
<__main__.Student object at 0x000001A2B3C4D5E6>

With __str__

class Student:
    def __init__(self, name, grade):
        self.name = name
        self.grade = grade

    def __str__(self):
        return f"Student({self.name}, grade={self.grade})"

s = Student("Ravi", "A")
print(s)
Student(Ravi, grade=A)

print() automatically calls __str__ on any object.

📏 2. __len__ — Works with len()

class Classroom:
    def __init__(self, students):
        self.students = students

    def __len__(self):
        return len(self.students)

room = Classroom(["Ravi", "Sita", "Amit"])
print(len(room))
3

⚖️ 3. __eq__ — Works with ==

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

p1 = Point(2, 3)
p2 = Point(2, 3)
print(p1 == p2)
True
💡 Without __eq__, == compares object identity (are they the same object in memory) — p1 == p2 would be False even with identical values.

➕ 4. __add__ — Works with +

class Money:
    def __init__(self, amount):
        self.amount = amount

    def __add__(self, other):
        return Money(self.amount + other.amount)

    def __str__(self):
        return f"₹{self.amount}"

wallet = Money(500) + Money(250)
print(wallet)
₹750

🧑‍💻 Practice

🚀 Challenge: Add __str__ and __len__ to a Playlist class holding a list of songs. 
class Playlist:
    def __init__(self, name, songs):
        self.name = name
        self.songs = songs

    def __str__(self):
        return f"Playlist '{self.name}' with {len(self.songs)} songs"

    def __len__(self):
        return len(self.songs)

p = Playlist("Road Trip", ["Song A", "Song B", "Song C"])
print(p)        # Playlist 'Road Trip' with 3 songs
print(len(p))   # 3

✍️ Chapter Summary

  • Dunder methods = double-underscore methods Python calls automatically
  • __str__ — controls print() output
  • __len__ — controls len()
  • __eq__, __lt__ — control comparisons
  • __add__ — controls the + operator
