Date & Time

Work with dates, times, and durations using the datetime module.

📅 Today, Tomorrow, and Everything Between

Booking systems, attendance trackers, deadlines — almost every real app needs to store and calculate dates. Python's datetime module handles it.

⚡ 1. Getting the Current Date & Time

from datetime import datetime

now = datetime.now()
print(now)
print(now.year, now.month, now.day)
print(now.hour, now.minute, now.second)
2026-07-09 14:32:07.812345 2026 7 9 14 32 7

🎨 2. Formatting Dates — strftime

from datetime import datetime

now = datetime.now()
print(now.strftime("%d-%m-%Y"))          # 09-07-2026
print(now.strftime("%A, %B %d, %Y"))     # Thursday, July 09, 2026
print(now.strftime("%H:%M:%S"))          # 14:32:07
09-07-2026 Thursday, July 09, 2026 14:32:07
CodeMeaningExample
%Y4-digit year2026
%m2-digit month07
%d2-digit day09
%AFull weekday nameThursday
%BFull month nameJuly
%H:%M:%S24-hour time14:32:07

📥 3. Parsing a Date From Text — strptime

from datetime import datetime

text = "15-08-2026"
date_obj = datetime.strptime(text, "%d-%m-%Y")

print(date_obj)
print(date_obj.year)
2026-08-15 00:00:00 2026
💡 strftime = date object → text. strptime = text → date object. Same format codes, opposite direction.

➕ 4. Date Math — timedelta

from datetime import datetime, timedelta

today = datetime(2026, 7, 9)
exam_date = today + timedelta(days=30)

print(exam_date)

due = datetime(2026, 7, 20)
days_left = (due - today).days
print(f"{days_left} days left")
2026-08-08 00:00:00 11 days left

timedelta represents a duration — add or subtract it from dates, or subtract two dates to get a duration.

⏱️ 5. Measuring Elapsed Time

import time

start = time.time()

total = sum(range(10_000_000))   # some work

end = time.time()
print(f"Took {end - start:.4f} seconds")
Took 0.6213 seconds

🧑‍💻 Practice

🚀 Challenge: Write a function days_until_birthday(birthday_str) that takes a date like "25-12-2026" and returns how many days from today until then. 
from datetime import datetime

def days_until_birthday(birthday_str):
    birthday = datetime.strptime(birthday_str, "%d-%m-%Y")
    today = datetime.now()
    return (birthday - today).days

print(days_until_birthday("25-12-2026"))

✍️ Chapter Summary

  • datetime.now() — current date and time
  • strftime(fmt) — date object → formatted string
  • strptime(text, fmt) — string → date object
  • timedelta(days=..) — a duration you can add/subtract from dates
  • time.time() — measure elapsed seconds
