🖼️ What is matplotlib?

matplotlib is a powerful plotting library in Python that turns raw data into beautiful charts.

It's like the artist in your Python toolkit 🎨

✍️ Basic Usage

import matplotlib.pyplot as plt
x = [1, 2, 3, 4]
y = [10, 20, 25, 30]
plt.plot(x, y)
plt.title("Basic Line Chart")
plt.xlabel("X Axis")
plt.ylabel("Y Axis")
plt.show()
🟢 A simple line chart with labeled axes and title.
PartPurpose
plt.plot(x, y)Draws the line connecting each (x, y) point
plt.title(...)Text shown above the chart
plt.xlabel() / plt.ylabel()Labels for each axis, so readers know the units
plt.show()Opens a window/renders the finished chart — nothing appears without it

🧱 Types of Charts

Chart TypeFunctionUse Case
Line Chartplot()Track change over time
Bar Chartbar()Compare categories
Pie Chartpie()Show parts of a whole
Histogramhist()Frequency of values
Scatter Plotscatter()Show relationships
💡 Ask "what am I comparing?" — trend over time → line. Comparing separate categories → bar. Parts of one whole (percentages that add to 100%) → pie. Is X related to Y? → scatter. How spread out are my values? → histogram.

📊 Bar Chart Example

import matplotlib.pyplot as plt
students = ["Aman", "Elon", "John"]
marks = [85, 90, 75]
plt.bar(students, marks, color='skyblue')
plt.title("Student Marks")
plt.xlabel("Names")
plt.ylabel("Marks")
plt.show()

color='skyblue' sets the bar fill color — accepts named colors ("red", "green") or hex codes ("#ff5733").

📈 Multiple Lines & Legends

Plot several series on the same chart by calling plt.plot() more than once before plt.show(). Use label= and plt.legend() so readers know which line is which.

days = [1, 2, 3, 4, 5]
maths_marks = [60, 70, 75, 80, 85]
science_marks = [65, 68, 74, 78, 90]

plt.plot(days, maths_marks, label="Maths", color="blue", marker="o")
plt.plot(days, science_marks, label="Science", color="green", marker="o")
plt.title("Marks Over 5 Tests")
plt.xlabel("Test Number")
plt.ylabel("Marks")
plt.legend()      # shows the label box so lines are distinguishable
plt.show()
🟢 Two colored lines (blue = Maths, green = Science) with a legend box in the corner.
ParameterEffect
label="Maths"Text shown for this line in the legend
marker="o"Draws a dot at each data point (try "s" for square, "^" for triangle)
plt.legend()Renders the label box — without it, labels are set but never shown

📑 Figure Size & Multiple Subplots

plt.figure(figsize=(8, 4))   # width=8 inches, height=4 inches — call before plotting
plt.plot(days, maths_marks)
plt.title("Wider Chart")
plt.show()

To show two charts side by side, use plt.subplot(rows, cols, position):

plt.subplot(1, 2, 1)          # 1 row, 2 columns, this is chart #1
plt.plot(days, maths_marks)
plt.title("Maths")

plt.subplot(1, 2, 2)          # this is chart #2
plt.bar(students, marks)
plt.title("Marks by Student")

plt.tight_layout()            # prevents titles/labels overlapping
plt.show()
🟢 Two separate charts rendered side by side in one figure.

🥨 Pie Chart Example

subjects = ["Math", "Science", "English"]
time_spent = [5, 3, 2]
plt.pie(time_spent, labels=subjects, autopct='%1.1f%%')
plt.title("Time Spent per Subject")
plt.show()
🟢 A pie chart with 3 slices, each labeled with its subject name and percentage (e.g. "50.0%").

autopct='%1.1f%%' tells matplotlib to print the percentage on each slice, rounded to 1 decimal place. It's a format string: %1.1f means "1 digit before the decimal, 1 after," and %% prints a literal % sign. Without autopct, slices show only their label — no numbers.

📉 Scatter Plot Example

x = [1, 2, 3, 4, 5]
y = [2, 4, 1, 8, 7]
plt.scatter(x, y, color='red')
plt.title("Scatter Plot")
plt.xlabel("X values")
plt.ylabel("Y values")
plt.show()
