🪵 Chapter 32

Logging

Record what your program is doing — with severity levels, timestamps, and file output — instead of scattering print() everywhere.

🪵

🪵 Better Than print()

print() is fine for quick checks. But real programs need a permanent, filterable record of what happened — that's what the logging module gives you.

⚡ 1. Basic Logging

import logging

logging.basicConfig(level=logging.INFO)

logging.debug("This won't show — below INFO level")
logging.info("Server started")
logging.warning("Disk space running low")
logging.error("Failed to connect to database")
logging.critical("System is shutting down")
INFO:root:Server started WARNING:root:Disk space running low ERROR:root:Failed to connect to database CRITICAL:root:System is shutting down

logging.debug() was skipped because the configured level is INFO — only messages at that level or higher are shown.

📊 2. Log Levels — Lowest to Highest

LevelUsed for
DEBUGDetailed info for diagnosing problems
INFOConfirmation that things are working normally
WARNINGSomething unexpected, but program still works
ERRORA serious problem — some function failed
CRITICALProgram may not be able to continue
💡 Setting level=logging.WARNING shows WARNING, ERROR, and CRITICAL — but hides DEBUG and INFO. Set the level based on how much detail you want to see.

🎨 3. Custom Format With Timestamps

import logging

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s"
)

logging.info("Attendance marked for Ravi")
logging.warning("Late submission from Sita")
2026-07-09 14:20:11,502 - INFO - Attendance marked for Ravi 2026-07-09 14:20:11,503 - WARNING - Late submission from Sita

📄 4. Logging to a File

import logging

logging.basicConfig(
    filename="app.log",
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s"
)

logging.info("Application started")
logging.error("Payment gateway timeout")
# messages are written to app.log instead of the terminal
ℹ️ File logs stay after the program closes — great for debugging issues that happened while nobody was watching the terminal.

🧭 5. Named Loggers (Per Module)

import logging

logger = logging.getLogger("student_service")
logger.setLevel(logging.INFO)

handler = logging.StreamHandler()
formatter = logging.Formatter("%(name)s - %(levelname)s - %(message)s")
handler.setFormatter(formatter)
logger.addHandler(handler)

logger.info("Student record created")
student_service - INFO - Student record created

Named loggers let large projects tell which module a message came from.

✍️ Chapter Summary

  • logging.basicConfig(level=..) — set minimum severity to show
  • Levels, low to high: DEBUG, INFO, WARNING, ERROR, CRITICAL
  • filename="app.log" — write logs to a file instead of the terminal
  • format="..." — customize timestamp and message layout
  • logging.getLogger(name) — named logger for larger projects
