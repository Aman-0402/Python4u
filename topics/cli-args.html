💻 Chapter 31

Command-line Arguments

Let people configure your script from the terminal instead of editing the code every time.

💻

💻 Scripts That Take Instructions

Instead of hardcoding a filename or a number inside your script, let the user pass it in when they run the program — just like real command-line tools do.

⚡ 1. The Raw Way — sys.argv

# greet.py
import sys

name = sys.argv[1]
print(f"Hello, {name}!")
# terminal
$ python greet.py Ravi
Hello, Ravi!

sys.argv is a list of everything typed on the command line. sys.argv[0] is the script name itself, sys.argv[1] is the first argument, and so on.

⚠️ If the user forgets to pass an argument, sys.argv[1] raises IndexError. No built-in help text, no type checking — that's why argparse is preferred for real tools.

🛠️ 2. The Proper Way — argparse

# greet.py
import argparse

parser = argparse.ArgumentParser(description="Greet someone by name")
parser.add_argument("name", help="the person's name")
parser.add_argument("--formal", action="store_true", help="use a formal greeting")

args = parser.parse_args()

if args.formal:
    print(f"Good day, {args.name}.")
else:
    print(f"Hey {args.name}!")
# terminal
$ python greet.py Ravi
$ python greet.py Ravi --formal
Hey Ravi! Good day, Ravi.

🆓 3. Free Help Text

# terminal
$ python greet.py --help
usage: greet.py [-h] [--formal] name Greet someone by name positional arguments: name the person's name options: -h, --help show this help message and exit --formal use a formal greeting

argparse generates this --help output automatically from your add_argument() calls — no extra work needed.

🔢 4. Optional Arguments With Values

import argparse

parser = argparse.ArgumentParser(description="Calculate simple interest")
parser.add_argument("principal", type=float, help="loan amount")
parser.add_argument("--rate", type=float, default=5.0, help="interest rate percent (default 5.0)")
parser.add_argument("--years", type=int, default=1, help="number of years (default 1)")

args = parser.parse_args()
interest = args.principal * args.rate / 100 * args.years
print(f"Interest: {interest}")
# terminal
$ python interest.py 10000 --rate 8 --years 3
Interest: 2400.0

🧑‍💻 Practice

🚀 Challenge: Build a CLI tool square.py that takes a required integer number and prints its square. 
import argparse

parser = argparse.ArgumentParser(description="Print the square of a number")
parser.add_argument("number", type=int, help="the number to square")
args = parser.parse_args()

print(args.number ** 2)

# terminal: python square.py 7  -->  49

✍️ Chapter Summary

  • sys.argv — raw list of command-line words, no validation
  • argparse — parses arguments, auto-generates --help
  • add_argument("name") — required positional argument
  • add_argument("--flag", action="store_true") — optional on/off flag
  • type=int / type=float — auto-converts input text
