🧮 Chapter 18

Comprehensions

Build a new list, dict, or set in one readable line instead of a multi-line loop.

🧮

🧮 One Line, One Result

A comprehension takes a loop + a condition and squeezes them into a single expression. Same result, less code, easier to read once you know the pattern.

⚡ 1. List Comprehension

Pattern: [expression for item in iterable if condition]

Without comprehension

numbers = [1, 2, 3, 4, 5, 6]
squares = []
for n in numbers:
    squares.append(n * n)
print(squares)
[1, 4, 9, 16, 25, 36]

With comprehension

numbers = [1, 2, 3, 4, 5, 6]
squares = [n * n for n in numbers]
print(squares)
[1, 4, 9, 16, 25, 36]

📋 Student Marks Example

marks = [55, 90, 42, 78, 61, 30]
passed = [m for m in marks if m >= 40]
print(passed)
[55, 90, 42, 78, 61]

Only marks >= 40 (the condition) make it into the new list.

💡 Use a comprehension when the loop body is just "build a list from this." If the loop does several things (print, save to file, update a counter), keep the normal for loop.

🗂️ 2. Dictionary Comprehension

Pattern: {key: value for item in iterable}

names = ["Ravi", "Sita", "Amit"]
name_lengths = {name: len(name) for name in names}
print(name_lengths)
{'Ravi': 4, 'Sita': 4, 'Amit': 4}

Building from two lists

students = ["Ravi", "Sita", "Amit"]
scores   = [78, 92, 65]

report = {student: score for student, score in zip(students, scores)}
print(report)
{'Ravi': 78, 'Sita': 92, 'Amit': 65}

🔷 3. Set Comprehension

Same idea, but wrapped in { } without a colon — produces unique values only.

words = ["apple", "banana", "apple", "cherry", "banana"]
unique_lengths = {len(w) for w in words}
print(unique_lengths)
{5, 6}

🌀 4. Nested Comprehension

Flatten a list of lists — common with grid or matrix data.

matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flat = [num for row in matrix for num in row]
print(flat)
[1, 2, 3, 4, 5, 6, 7, 8, 9]
TypeSyntaxReturns
List[x for x in y]list
Dict{k: v for x in y}dict
Set{x for x in y}set
Generator(x for x in y)generator object
⚠️ Don't nest more than 2 levels — it gets hard to read. If it stops fitting on one clear line, go back to a normal loop.

🔀 5. Conditional Expression — if / else Inside the Comprehension

This is different from the filtering if in section 1. That one drops items. This one transforms every item into one of two values — it sits right after the expression, before the for.

Pattern: [value_if_true if condition else value_if_false for item in iterable]

marks = [55, 90, 42, 30, 78]
results = ["Pass" if m >= 40 else "Fail" for m in marks]
print(results)
['Pass', 'Pass', 'Pass', 'Fail', 'Pass']

Notice the list is still the same length as marks — nothing was dropped, every mark became a label.

⚠️ Easy to confuse the two forms. Filtering if goes at the end and removes items: [m for m in marks if m >= 40]. Conditional if/else goes at the start and transforms items: [x if x >= 40 else 0 for x in marks]. You can even combine both in one comprehension if needed.

Combining both forms

# Keep only failing students, label them clearly
failed = [f"{m} - Needs improvement" if m < 40 else f"{m} - OK" for m in marks if m < 60]
print(failed)
['30 - Needs improvement']

⚖️ 6. List Comprehension vs Generator Expression

Both use nearly identical syntax, but they behave very differently — this matters once your data gets large.

numbers = range(1000000)

list_version = [n * n for n in numbers]      # builds all 1,000,000 results NOW, in memory
gen_version  = (n * n for n in numbers)      # builds nothing yet — produces values on demand
List comprehension [ ]Generator expression ( )
MemoryStores every result at onceStores almost nothing — lazy
Speed to createSlower for huge data (builds now)Instant (nothing computed yet)
Can loop over it twice?Yes, reusableNo — exhausted after one pass
Use whenYou need the full list, indexing, or multiple passesYou're processing once, or the data is huge/infinite
💡 Rule of thumb: if you're about to pass the result straight into sum(), max(), or a single for loop and never need it again, use a generator expression — it's more memory-efficient with no downside. See Iterators & Generators for the full picture.

🚀 Challenge 1: Given prices = [250, 40, 999, 15, 620], build a list of only prices above 100 using a list comprehension. 
prices = [250, 40, 999, 15, 620]
expensive = [p for p in prices if p > 100]
print(expensive)   # [250, 999, 620]
🚀 Challenge 2: Given words = ["cat", "elephant", "dog", "hippopotamus"], build a dict mapping each word to its length. 
words = ["cat", "elephant", "dog", "hippopotamus"]
lengths = {w: len(w) for w in words}
print(lengths)   # {'cat': 3, 'elephant': 8, 'dog': 3, 'hippopotamus': 12}

✍️ Chapter Summary

  • [expr for x in y] — list comprehension
  • {k: v for x in y} — dict comprehension
  • {expr for x in y} — set comprehension
  • Add if condition at the end to filter
  • Keep it to one clear line — otherwise use a normal loop
