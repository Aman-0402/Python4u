🔧 Before You Write Python, Install Python

Even Iron Man had to set up his suit before flying. No shortcuts here. Ten minutes now, zero pain forever.

🐍 1. Install Python

Download from the official source only. Not your neighbour's USB. Not some random site.

💡 Always install Python 3.10+. Python 2 is dead. Don't dig it up.
  1. Open browser → go to python.org/downloads
  2. Click "Download Python 3.x.x" (big yellow button)
  3. Run the installer .exe
  4. ⚠️ CRITICAL: tick "Add Python to PATH" at the bottom before clicking Install
  5. Click Install Now → wait → Done
⚠️ Missed the "Add to PATH" checkbox? Uninstall, reinstall, tick it. Or Google "add Python to PATH manually" — your call.
  1. Option A — Official installer: python.org/downloads → download .pkg → run it
  2. Option B (recommended) — use Homebrew: 
    brew install python3
  3. macOS ships Python 2.7 as python. Always use python3 command
  1. Python 3 is usually pre-installed. Check first (see Section 2)
  2. If missing, Ubuntu/Debian: 
    sudo apt update
sudo apt install python3 python3-pip
  3. Fedora/RHEL: 
    sudo dnf install python3

🔎 2. Verify Python is Installed

Open terminal (CMD / PowerShell / Terminal) and run:

python --version

If that gives an error, try:

python3 --version

Expected output (version number will vary):

Python 3.12.4
✅ If you see Python 3.x.x — you're good. Close this tab. Stop worrying.

📦 Check pip (package installer)

pip --version
pip 24.0 from C:\Python312\Lib\site-packages\pip (python 3.12)
💡 pip installs third-party libraries. pip install numpy, pip install flask etc. You'll use it constantly.

💻 3. Install VS Code

VS Code = best free editor for Python. Lightweight, extensible, not cursed like Notepad.

  1. Go to code.visualstudio.com
  2. Download for your OS → run installer
  3. Open VS Code → press Ctrl+Shift+X to open Extensions panel
  4. Search and install extensions listed below
💡 To open a folder in VS Code: File → Open Folder or drag folder onto VS Code window. Always open the project folder, not individual files.

🔎 How to install extension

  1. Press Ctrl + Shift + X in VS Code
  2. Type extension name in search box
  3. Click Install button
  4. Done — no restart needed for most extensions

▶ 5. Write Your First Python File

  1. Open VS Code → File → New File
  2. Save as hello.py (the .py extension activates Python mode)
  3. Type the code below
  4. Press Ctrl + F5 to run (or click the ▶ button top-right)
print("Hello, World!")
print("Python is installed. Tom would be proud.")
print(f"Python version check: use  python --version  in terminal")
Hello, World! Python is installed. Tom would be proud. Python version check: use python --version in terminal
💡 No output? Check the Python interpreter in VS Code bottom bar — it must point to your installed Python 3.x. Click it to change.
