🔁 Chapter 19

Iterators & Generators

How for loops actually work under the hood, and how to build memory-efficient data streams.

🔁

🔁 One Value at a Time

A generator produces values one at a time, on demand, instead of building the whole list in memory first. Useful for big data or infinite sequences.

⚡ 1. What is an Iterator?

An iterator is any object you can loop over with next(). Lists, strings, dicts are iterable — call iter() on them to get an iterator.

numbers = [10, 20, 30]
it = iter(numbers)

print(next(it))   # 10
print(next(it))   # 20
print(next(it))   # 30
print(next(it))   # raises StopIteration
10 20 30 Traceback... StopIteration

A for loop does this automatically — it calls iter(), then next() repeatedly, and stops when it catches StopIteration.

🌱 2. Generator Functions — yield

A function with yield instead of return becomes a generator. Each call to next() resumes right where it left off.

Regular function (builds full list)

def get_even_numbers(limit):
    result = []
    for n in range(limit):
        if n % 2 == 0:
            result.append(n)
    return result

print(get_even_numbers(10))
[0, 2, 4, 6, 8]

Generator function (produces one at a time)

def get_even_numbers(limit):
    for n in range(limit):
        if n % 2 == 0:
            yield n

for num in get_even_numbers(10):
    print(num)
0 2 4 6 8
💡 The generator never stores the whole list in memory — it hands out one value, pauses, and waits for the next next() call. Great for huge files or endless streams.

📄 3. Real Example — Reading a Big File Line by Line

def read_large_file(filename):
    with open(filename) as f:
        for line in f:
            yield line.strip()

# Only one line is in memory at a time, even for a 10 GB file
for line in read_large_file("orders.txt"):
    print(line)
ℹ️ Loading a huge file with .readlines() puts every line in RAM at once. A generator reads and processes one line, then discards it.

🧪 4. Generator Expressions

Same idea as a list comprehension, but with ( ) instead of [ ] — values are made lazily, not all at once.

squares_list = [n * n for n in range(1000000)]   # builds all 1,000,000 now
squares_gen  = (n * n for n in range(1000000))    # builds nothing yet

print(next(squares_gen))   # 0
print(next(squares_gen))   # 1
0 1

🧑‍💻 Practice

🚀 Challenge: Write a generator countdown(n) that yields numbers from n down to 1. 
def countdown(n):
    while n > 0:
        yield n
        n -= 1

for num in countdown(5):
    print(num)
# 5 4 3 2 1

✍️ Chapter Summary

  • iter() gets an iterator; next() pulls one value
  • yield pauses a function and returns a value — resumes on next call
  • Generator expressions: (x for x in y) — lazy, memory-friendly
  • Use generators for large or infinite data streams
