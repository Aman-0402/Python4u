📦 Variables — Python's Memory Box

Store anything. Change it anytime. Python won't judge you. (Unlike Java.)

📦 1. What is a Variable?

Variable = labelled box. You put stuff inside. Python remembers it — unlike your ex.

🤖 Analogy: Naruto's Jutsu Memory

Naruto needs to remember his moves. So his brain stores:

  • favourite_jutsu = "Rasengan"
  • chakra_level = 9999
  • is_hokage = True

Change chakra_level = 0 → Naruto is now just a loud kid from Konoha with no plan.

hero = "Naruto"
chakra = 9999
is_hokage = True

print(hero, "has", chakra, "chakra units")
print("Is Hokage?", is_hokage)
Naruto has 9999 chakra units Is Hokage? True
💡
Syntax: variable_name = value
No int, no var, no let. Python just… vibes.

🛑 Variable Naming Rules

🎨 2. Python Data Types

Python needs to know what kind of data it's storing. Not all heroes wear capes. Not all variables hold numbers.

int
Whole numbers. No drama, no decimals.
power_level = 9001
float
Decimal numbers. Fancy integers.
accuracy = 97.3
str
Text. Wrapped in quotes like a burrito.
hero = "Iron Man"
bool
True or False. No maybe. Python doesn't do "maybe".
is_alive = True
list
Ordered, changeable collection. Like the Avengers roster.
avengers = ["Tony", "Steve"]
tuple
List but frozen. Immutable. Like Thanos's decision.
infinity_stones = (6,)
dict
Key-value pairs. Pokemon stats sheet.
pikachu = {"hp": 35}
set
Unique values only. No duplicates. Like DNA.
unique_moves = {1, 2, 3}

📊 Avengers Data Sheet (real example)

hero = "Tony Stark"          # str   — billionaire, genius, showoff
suits_count = 85             # int   — yes, 85 suits. Overachiever.
battery_pct = 99.7           # float — Arc Reactor never fully charges. Classic.
is_alive = False             # bool  — thanks, Thanos (spoilers, sorry)

🧑‍💻 Check the Type — Python's `type()`

print(type(suits_count))  # <class 'int'>
print(type(is_alive))     # <class 'bool'>
print(type(stats))        # <class 'dict'>
<class 'str'> <class 'int'> <class 'bool'> <class 'dict'>

🔄 Type Conversion (Casting)

Need to convert? Python handles it. Like Pikachu evolving into Raichu — same soul, different form.

level = "99"           # str — useless for math
level_int = int(level) # int — now we're talking
print(level_int + 1)   # 100 — max level unlocked

power = 9001
power_str = str(power)
print("Power level: " + power_str)  # string join now works
100 Power level: 9001
⚠️ int("nine thousand") crashes. Python can't magic-guess. Only numbers-in-strings work. int("9000") ✅ — int("nine thousand") ❌

🍔 Thanos Snap Calculator

🤵 Scenario: Thanos snaps half the universe. Let's do the math with Python — because even genocide should be PEP8 compliant. 
universe_population = 8_000_000_000   # 8 billion humans
snapped = universe_population // 2
survivors = universe_population - snapped
snap_percent = (snapped / universe_population) * 100

print(f"Snapped: {snapped:,}")        # 4,000,000,000
print(f"Survivors: {survivors:,}")    # 4,000,000,000
print(f"Gone: {snap_percent:.0f}%")   # 50%
print("Balanced, as all things should be.")
Snapped: 4,000,000,000 Survivors: 4,000,000,000 Gone: 50% Balanced, as all things should be.

💻 E. Bitwise Operators

Binary-level operations. Used in encryption, hardware, and interviews to make you sweat.

OperatorNameExampleResult
&AND5 & 31
|OR5 | 37
^XOR5 ^ 36
~NOT~5-6
<<Left Shift5 << 110
>>Right Shift5 >> 12
 
a = 5      # binary: 0101
b = 3      # binary: 0011
print(a & b)   # 1  — only bits BOTH have
print(a | b)   # 7  — bits EITHER has
print(a ^ b)   # 6  — bits only ONE has (exclusive)
print(~a)      # -6 — flip all bits, cry a little
print(a << 1)  # 10 — shift left = multiply by 2
print(a >> 1)  # 2  — shift right = divide by 2
1 7 6 -6 10 2
🕐 Interview Trick: Check even/odd with bitwise — num & 1 returns 1 if odd, 0 if even. Faster than %. Sounds smarter in interviews. Use it.

🧪 Coding Challenges

🚀 Challenge 1: Dragon Ball Power Check
Store Goku's power level as 9001. Print: "IT'S OVER 9000!" using string + variable. 
power_level = 9001
print("It's OVER " + str(power_level - 1) + "!")
💡 Must convert int → str before joining with +. Or use f-string: f"It's OVER {power_level - 1}!"
🚀 Challenge 2: Tony Stark's Suit Report
Variables: suit_count = 85, broken = 12. Calculate working suits. Print: "Working suits: X. That's still overkill." 
suit_count = 85
broken = 12
working = suit_count - broken
print(f"Working suits: {working}. That's still overkill.")
🚀 Challenge 3: Even or Odd (Bitwise)
Use & 1 to check if a number is even or odd. No % allowed. 
num = 42
if num & 1:
    print(f"{num} is Odd")
else:
    print(f"{num} is Even")  # correct — 42 is famously even AND the answer to everything
💡 num & 1 checks last binary bit. 1 = odd, 0 = even.

✍️ Chapter Summary

  • Variable = named container. x = 5 — no type declaration needed.
  • 8 main data types: int, float, str, bool, list, tuple, dict, set.
  • type() tells you what something is. Like a label on Naruto's chakra jar.
  • Arithmetic: + - * / // % ** — do math.
  • Comparison: == != > < >= <= — returns True/False.
  • Logical: and or not — combine conditions.
  • Assignment shortcuts: += -= *= /= etc.
  • Bitwise: & | ^ ~ << >> — binary-level ops. Interview gold.
