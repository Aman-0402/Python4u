🌐 Introduction to Web APIs and JSON

APIs are like waiters in a restaurant — they take your order to the kitchen and bring back the food!

🤔 Why Learn APIs?

  • Get live weather, news, sports scores 📰
  • Access data from platforms like YouTube, Twitter, or Google 🌍
  • Control smart devices, chatbots, and more 💬

📦 What is an API?

API stands for Application Programming Interface. It lets two programs talk to each other.

🍔 Real-Life Analogy

  • You 🧑: "I want a pizza!"
  • Waiter 🧑‍🍳 (API): Takes your order to the kitchen.
  • Kitchen 🔥 (Server): Makes the pizza (data).
  • Waiter brings it back to your table.

Same way: Your Python app → API → Server → API → Your app gets data!

🔢 What is JSON?

JSON = JavaScript Object Notation. The language of data used by most APIs — just text formatted as structured data.

{
  "name": "Aman",
  "age": 20,
  "subjects": ["Math", "Python", "AI"]
}

Looks like a Python dictionary, right? Exactly!

🛠️ How to Work with APIs in Python

You'll use a module called requests:

pip install requests

🔗 Example: Fetching Data from a Free API

import requests
response = requests.get("https://api.agify.io/?name=aman")
data = response.json()
print(data)
print("Predicted Age:", data["age"])
{'name': 'aman', 'age': 25, 'count': 100} Predicted Age: 25

🌆 Real-World Example: Get Weather Info

import requests
city = "London"
url = f"http://api.weatherapi.com/v1/current.json?key=your_api_key&q={city}"
response = requests.get(url)
data = response.json()
print("Temperature:", data['current']['temp_c'], "°C")

(Note: You need an API key 🔑 — sign up free on weatherapi.com)

⚠️ Handling Errors — Requests Fail Too

Networks drop, servers go down, wrong URLs happen. Never assume requests.get() always succeeds.

import requests

try:
    response = requests.get("https://api.agify.io/?name=aman", timeout=5)
    response.raise_for_status()   # raises an error if status is 4xx or 5xx
    data = response.json()
    print("Predicted Age:", data["age"])
except requests.exceptions.Timeout:
    print("Request took too long — server didn't respond in time.")
except requests.exceptions.ConnectionError:
    print("No internet connection or server unreachable.")
except requests.exceptions.HTTPError as e:
    print(f"Server returned an error: {e}")
Predicted Age: 25
Status CodeMeaning
200OK — request succeeded
400Bad Request — your request was malformed
401Unauthorized — missing/invalid API key
404Not Found — wrong URL/endpoint
500Server Error — problem on their end, not yours
💡 timeout=5 stops your program from hanging forever if the server never responds. Always set one for real projects.

🔑 Headers, Params & Authentication

Many APIs need extra information sent along with the request — an API key, or query filters.

import requests

url = "https://api.example.com/students"
headers = {"Authorization": "Bearer YOUR_API_KEY"}
params = {"grade": "A", "limit": 10}

response = requests.get(url, headers=headers, params=params)
print(response.url)   # shows the final URL with params attached
https://api.example.com/students?grade=A&limit=10

params is safer and cleaner than manually building a URL with f-strings — requests handles the ?key=value&key2=value2 formatting and character escaping for you.

📤 POST — Sending Data to an API

GET asks for data. POST sends new data — like submitting a form (creating a student record, posting a comment).

import requests

url = "https://api.example.com/students"
new_student = {"name": "Ravi", "grade": "A", "marks": 88}

response = requests.post(url, json=new_student)
print(response.status_code)
print(response.json())
201 {'id': 42, 'name': 'Ravi', 'grade': 'A', 'marks': 88}

json=new_student automatically converts the dict to a JSON string and sets the right content-type header. Status 201 means "Created" — a new resource was successfully added.

📜 The json Module — Working With JSON as Text

Not all JSON comes from an API call. You'll sometimes have raw JSON text (from a file or a string) that needs converting.

import json

# JSON text -> Python dict
json_text = '{"name": "Aman", "age": 20, "subjects": ["Math", "Python"]}'
data = json.loads(json_text)
print(data["name"])
print(type(data))
Aman <class 'dict'>
# Python dict -> JSON text
student = {"name": "Sita", "age": 21}
json_text = json.dumps(student, indent=2)
print(json_text)
{ "name": "Sita", "age": 21 }
FunctionDirection
json.loads(text)JSON string → Python dict/list
json.dumps(obj)Python dict/list → JSON string
response.json()Shortcut: does json.loads() on an API response automatically
