⚙️ Functions — Reusable Code Machines

Without functions, every program looks like Tom's plans to catch Jerry. Lots of effort. Zero reuse. Same result.

📦 1. What is a Function?

Function = named block of code you can call anytime, as many times as you want. Write once, run forever. Like Jerry's escape routes — always available, always works.

🐱 Tom's Chase Strategy

Tom runs the SAME chase sequence every single day:

  • Spot Jerry 🐛
  • Run at full speed 🐇
  • Crash into wall 💥
  • Lie flat on floor 💀

That's a function. Same steps, called every episode. Tom just never checks the return value.

def chase_jerry(speed, direction): # ← keyword + name + params
    if speed > 100:
        return "caught jerry" # ← return sends value back
    return "wall crash 💥"

result = chase_jerry(50, "left") # ← calling the function 
def chase_jerry(speed, direction):
    if speed > 100:
        return "Caught Jerry! ...wait, no."
    return f"Crash into wall going {direction}. Again."

print(chase_jerry(50, "left"))
print(chase_jerry(200, "right"))
Crash into wall going left. Again. Caught Jerry! ...wait, no.

🔎 2. Parameters & Arguments

Parameters = variables in function definition. Arguments = actual values you pass when calling. Like the difference between "a sandwich" (parameter) vs "a Krabby Patty" (argument).

🫕 Homer's Donut Order — *args

def homer_orders(*donuts):
    print(f"Homer wants {len(donuts)} donuts:")
    for d in donuts:
        print(f"  🥑 {d}")
    print("Mmmmm... donuts. 😋")

homer_orders("glazed", "chocolate", "sprinkle", "pink frosted", "maple")
Homer wants 5 donuts: 🥑 glazed 🥑 chocolate 🥑 sprinkle 🥑 pink frosted 🥑 maple Mmmmm... donuts. 😋
💡 Order of params: positional → *args → defaults → **kwargs. Mix them up → SyntaxError. Python's grammar is stricter than English class.

↩️ 3. The return Statement

return sends a value back and immediately exits the function. No return → function returns None. Like asking Mr. Bean a question — technically he answered, but you got nothing useful.

🇤 Mr. Bean's Disaster Calculator

def calculate_damage(chairs_knocked, vases_broken, people_embarrassed):
    damage_score = chairs_knocked * 10 + vases_broken * 50 + people_embarrassed * 5
    return damage_score  # sends the number back

morning = calculate_damage(3, 2, 8)
print(f"Morning damage score: {morning}")  # we can USE this value now

total = calculate_damage(1, 0, 15) + calculate_damage(5, 3, 20)
print(f"Full day damage: {total}")
Morning damage score: 170 Full day damage: 280

💡 return vs print — The Classic Trap

def say_hi():
    print("Hi!")       # SHOWS on screen

def give_hi():
    return "Hi!"       # SENDS value back

x = say_hi()           # prints "Hi!" but x = None
y = give_hi()          # nothing prints but y = "Hi!"

print("x is:", x)      # x is: None
print("y is:", y)      # y is: Hi!
Hi! x is: None y is: Hi!
⚠️ print() shows it on screen. return gives it back to the caller. They are NOT the same. Confusing them is the #1 beginner mistake.

📖 Multiple Return Values

def bugs_bunny_stats():
    name = "Bugs Bunny"
    catchphrase = "What's up, Doc?"
    escapes = 9999
    return name, catchphrase, escapes  # Python packs as tuple

who, quote, count = bugs_bunny_stats()  # unpack
print(f"{who} says '{quote}' after {count} escapes.")
Bugs Bunny says 'What's up, Doc?' after 9999 escapes.

🫕 math module — Homer's Donut Geometry

from datetime import datetime, timedelta

🚀 Challenge 2: Bugs Bunny IQ Sorter
Given list of (name, iq) tuples, use sorted() with a lambda key to sort by IQ descending. Print each name + IQ. 
looney_tunes = [
    ("Bugs Bunny",  200),
    ("Elmer Fudd",   30),
    ("Tweety Bird", 140),
    ("Daffy Duck",   80),
    ("Road Runner", 175),
]

ranked = sorted(looney_tunes, key=lambda x: x[1], reverse=True)
for name, iq in ranked:
    print(f"{name}: IQ {iq}")
💡 key=lambda x: x[1] tells sorted() to compare tuples by their second element (IQ). reverse=True = highest first.
🚀 Challenge 3: Scooby-Doo Mystery Module
Create functions: investigate(location), unmask(villain), celebrate(). Call all three for one complete mystery. 
def investigate(location):
    return f"Gang heads to {location}... it's probably nothing."

def unmask(villain):
    return f"JINKIES! It was {villain} all along!"

def celebrate(solved=True):
    if solved:
        return "Scooby-Dooby-Doo! 🍕🍕🍕"
    return "We'll get 'em next time, gang."

# Run a complete mystery
print(investigate("Haunted Amusement Park"))
print(unmask("The Park Manager, Old Jenkins"))
print(celebrate())
