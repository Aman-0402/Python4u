🚨 Control Flow — Who's in Charge?

Without control flow, Python just runs top to bottom. Boring. Like a straight road with no traffic lights.

🎯 What is Control Flow?

Control flow decides which code runs, when it runs, and how many times. Python executes line by line — until you add decisions and loops. Then it gets interesting.

🤔

if / elif / else

Make decisions. "If this, do that."

🔁

while loop

Repeat while condition is True.

🔄

for loop

Iterate over a sequence.

🛑

break / continue / pass

Emergency controls inside loops.

🕑 History: The term "control flow" dates to 1949 — Maurice Wilkes. Before that, programs just crashed into each other like bumper cars.

🤔 1. if / elif / else — Decision Making

Python checks a condition. If True → run the block. If False → skip it. Simple. No feelings involved.

if condition:
    # runs when condition is True
elif another_condition:
    # runs when first fails but this is True
else:
    # runs when everything above fails
⚠️ Indentation is MANDATORY. Python uses spaces to define blocks. 4 spaces. Not tabs. Not vibes. 4 spaces. Miss one → IndentationError.

🔥 Goku's Power Level Check

🤖 Scenario: Goku arrives at a battlefield. His scouter reads the enemy power level. Python decides what Goku should do — because Goku clearly can't. 
enemy_power = 9500
goku_power  = 9001

if enemy_power > 90000:
    print("Super Saiyan Blue — full power!")
elif enemy_power > goku_power:
    print("Super Saiyan — this is getting interesting!")
elif enemy_power == goku_power:
    print("Equal power — dramatic pause...")
else:
    print("Normal Goku — not even worth powering up.")
Super Saiyan — this is getting interesting!

🔁 2. Loops — Repeat Yourself (Without Getting Tired)

🔄 A. while Loop

while runs as long as condition stays True. If condition never becomes False → infinite loop → laptop fans scream → you cry.

while condition:
    # repeats until condition = False
🥬 SpongeBob at the Grill: SpongeBob flips Krabby Patties until his shift ends. He can't stop — Mr. Krabs is watching. 
patties_to_make = 5
made = 0

while made < patties_to_make:
    made += 1
    print(f"🍔 Krabby Patty #{made} — DONE!")

print("Shift over. SpongeBob cries from happiness.")
🍔 Krabby Patty #1 — DONE! 🍔 Krabby Patty #2 — DONE! 🍔 Krabby Patty #3 — DONE! 🍔 Krabby Patty #4 — DONE! 🍔 Krabby Patty #5 — DONE! Shift over. SpongeBob cries from happiness.
⚠️ Infinite loop trap: If you forget made += 1, condition never turns False. Loop runs forever. Python hates you now.

🔄 B. for Loop

for iterates over a sequence — list, string, range, whatever. Great when you know HOW MANY times to loop.

for item in sequence:
    # runs once per item

🆗 Ash Sending Pokémon

ash_team = ["Pikachu", "Charizard", "Squirtle", "Bulbasaur", "Snorlax", "Lapras"]

for pokemon in ash_team:
    print(f"Go, {pokemon}! I choose you!")
Go, Pikachu! I choose you! Go, Charizard! I choose you! Go, Squirtle! I choose you! Go, Bulbasaur! I choose you! Go, Snorlax! I choose you! Go, Lapras! I choose you!

📈 range() — Count-based loops

# range(stop)         → 0 to stop-1
# range(start, stop)  → start to stop-1
# range(start, stop, step) → jump by step

for i in range(1, 6):
    print(f"Round {i}: FIGHT!")
Round 1: FIGHT! Round 2: FIGHT! Round 3: FIGHT! Round 4: FIGHT! Round 5: FIGHT!
💡 Pro tip: range(3) = 0, 1, 2. NOT 1, 2, 3. Python counts from zero. Yes, still. Every time. You'll forget. Every time.

🧿 Enumerate — Index + Value together

avengers = ["Tony", "Steve", "Thor", "Natasha"]

for i, hero in enumerate(avengers, start=1):
    print(f"{i}. {hero} — reporting for duty")
1. Tony — reporting for duty 2. Steve — reporting for duty 3. Thor — reporting for duty 4. Natasha — reporting for duty

🛑 3. Loop Control — break, continue, pass

Emergency levers inside loops. Use with care. Or don't. Python won't judge.

KeywordWhat it doesAnalogy
break Exit loop immediately Batman hits the eject button in the Batmobile
continue Skip this iteration, next one Michael Scott skips boring agenda items in meetings
pass Do nothing (placeholder) Jon Snow: "I know nothing" — still needs to exist

🛑 break — Batman Stops the Hunt

criminals = ["Joker", "Riddler", "Target: Penguin", "Two-Face", "Bane"]

for criminal in criminals:
    if "Target" in criminal:
        print(f"Found him! Stopping at: {criminal}")
        break
    print(f"Scanning... {criminal}")
Scanning... Joker Scanning... Riddler Found him! Stopping at: Target: Penguin

⏭️ continue — Michael Scott Skips Work Talk

agenda = ["Sales report", "That's what she said", "Q4 targets", "Dundies prep", "Client meeting"]

print("Dwight's official meeting agenda:")
for item in agenda:
    if item in ["That's what she said", "Dundies prep"]:
        print(f"  Michael: 'Skip that one.' (skipping: {item})")
        continue
    print(f"  ✅ {item}")
Dwight's official meeting agenda: ✅ Sales report Michael: 'Skip that one.' (skipping: That's what she said) ✅ Q4 targets Michael: 'Skip that one.' (skipping: Dundies prep) ✅ Client meeting

🙏 pass — Jon Snow's Empty Function

def know_nothing():
    pass   # Jon Snow placeholder — will implement when he learns something

# pass prevents a SyntaxError on empty blocks
# Without pass, Python crashes: "Expected an indented block"

for i in range(5):
    pass   # TODO: add Night King logic here
💡 pass is a no-op — valid Python syntax that does absolutely nothing. Useful while writing skeleton code. Jon Snow would approve.

🛠️ Practical: S.H.I.E.L.D. Login System

Combines while + if/elif/else + break. Real-world pattern.

correct_password = "IAmIronMan3000"
attempts = 0
max_attempts = 3

print("🔒 S.H.I.E.L.D. SECURITY TERMINAL")

while attempts < max_attempts:
    password = input("Enter clearance code: ")
    attempts += 1

    if password == correct_password:
        print("✅ Welcome, Agent. Fury has been notified.")
        break
    else:
        left = max_attempts - attempts
        if left > 0:
            print(f"❌ Wrong code. {left} attempt(s) remaining.")
        else:
            print("🚫 ACCESS DENIED. Sending your location to Nick Fury.")
🔒 S.H.I.E.L.D. SECURITY TERMINAL Enter clearance code: avengers ❌ Wrong code. 2 attempt(s) remaining. Enter clearance code: IAmIronMan3000 ✅ Welcome, Agent. Fury has been notified.

🚀 Challenge 2: Luffy's Treasure Counter
Use for loop with range(1, 11). Skip multiples of 3 (continue). Stop when you hit 8 (break). Print each kept number. 
for chest in range(1, 11):
    if chest == 8:
        print(f"Chest {chest} — Found the One Piece! STOPPING.")
        break
    if chest % 3 == 0:
        print(f"Chest {chest} — booby trap, skip!")
        continue
    print(f"Chest {chest} — GOLD!")
💡 Order matters: check break condition BEFORE continue, otherwise 8 might get skipped if it's also divisible by 3.
🚀 Challenge 3: Guess the Number Game
Pick a secret number 1–10. Let user guess 3 times. Hint "too high" / "too low". Use while + break. 
import random

secret    = random.randint(1, 10)
attempts  = 0
max_tries = 3

print("🎮 Guess the number (1-10). You have 3 tries.")

while attempts < max_tries:
    guess = int(input(f"Attempt {attempts + 1}: "))
    attempts += 1

    if guess == secret:
        print(f"🎉 Correct! It was {secret}. You're not completely hopeless.")
        break
    elif guess < secret:
        print("Too low!")
    else:
        print("Too high!")
else:
    print(f"💩 Game over. It was {secret}. Shame.")
💡 The while...else block runs only if the loop finishes WITHOUT hitting break. Sneaky but useful.
